落言隐私政策

更新日期：2026年9月28日　|　生效日期：2026年9月28日

落言由齐赛军开发。本政策说明落言在录音、转写和管理记录时如何处理信息。落言以本机使用为设计方式：录音和文字保存在当前设备，不上传到开发者服务器。

一、我们处理哪些信息

  • 录音音频：仅在你主动开始录音并授予麦克风权限后采集，用于保存、播放和语音转写。
  • 文字内容：包括你填写的标题、离线语音识别生成的转写文字，以及你手动编辑或输入的文字，用于查看、修改、搜索和复制记录。
  • 记录与播放信息：包括记录日期和时间、音频时长、置顶状态、播放进度和所选倍速，用于按日期整理记录及恢复播放状态。

二、处理目的、方式和权限

录音只由你在界面点击录音按钮后启动；系统会在需要录音时请求麦克风权限。拒绝或撤销权限后，录音功能无法使用，你仍可手动输入文字。

语音转写由随应用提供的 Paraformer、SenseVoice 离线模型在当前设备完成。落言不把录音发送到云端语音识别服务。模型文件缺失或无法读取时，转写可能不可用，但不会因此将录音上传到服务器。

三、存储位置和保存期限

录音与记录文字保存在当前设备的应用本地存储中；播放进度和倍速偏好也保存在本地。内容会保留到你在应用内删除相应记录，或清除应用数据、卸载应用为止。卸载或清理本地数据后，通常无法恢复已删除的内容。

四、复制、共享和第三方服务

落言不要求注册账号，不提供云端同步，不接入广告或统计分析 SDK，也不会把录音、标题或转写文字提供给第三方。你点击“复制文字”时，所选文字会写入设备系统剪贴板；剪贴板是否被系统或其他应用同步、读取，取决于设备和相关应用的设置。

为提供本政策网页，页面托管在 GitHub Pages。访问本网页时，GitHub 会记录访问者 IP 地址用于安全目的，并按其隐私声明处理。访问政策网页不会把落言中的录音或记录内容发送给 GitHub。

五、你如何管理信息

  • 查看记录：在落言记录列表中打开对应内容。
  • 更正文字：打开记录后修改标题或转写文字。
  • 复制文字：使用记录中的复制功能；复制内容会进入系统剪贴板。
  • 删除信息：在记录菜单中删除单条记录；也可清除应用数据或卸载应用删除本机记录。
  • 管理麦克风权限：在设备系统设置中查看或撤销落言的麦克风权限。

六、录音中涉及他人信息

录音可能包含你或他人的个人信息。请在录制他人声音前确认已取得必要授权，并避免录入不必要的敏感信息。录音内容保存在本机，但设备使用者仍应妥善保护设备及其解锁凭据。

七、未成年人保护

落言不面向未满14周岁的儿童提供专门服务。未成年人使用落言时，应在监护人指导下进行；监护人应帮助其了解录音、转写和本地保存方式。

八、政策更新与联系

本政策发生与个人信息处理方式有关的实质变更时，我们会更新本页面，并按应用适用的方式提示你。对本政策或个人信息管理有疑问，可通过华为应用市场落言详情页展示的开发者联系渠道联系开发者齐赛军。

本政策仅描述落言自身的处理行为。设备系统、剪贴板及政策页面托管服务的处理方式，另受相应服务提供方的规则约束。
